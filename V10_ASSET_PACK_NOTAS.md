# V10 — Asset Pack Premium + UI infantil premium

## Entrega
Esta versão aproxima o app do padrão visual das referências enviadas pelo usuário usando:
- shell premium infantil com vitrine visual mais forte
- quick dock de navegação
- imagens de referência integradas como posters e painéis decorativos
- cartas de memória em estilo premium geradas automaticamente via SVG/data URI
- reforço visual em Packs, Eventos, Mapa, Recompensas, Pais e Jogo

## Pontos principais
- `public/v10/` contém imagens de referência usadas como apoio visual
- `src/App.tsx` contém integração do asset pack premium
- `src/index.css` contém a nova direção de arte V10
