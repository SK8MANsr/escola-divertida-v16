# Escola Divertida V8 – Premium Kids UI

## O que mudou
- shell visual novo inspirado nas referências premium infantis
- menu lateral funcional no desktop
- drawer lateral funcional no mobile
- janelas flutuantes/modais para abrir fases e jogos
- home, mapa, recompensas e painel dos pais em linguagem visual premium
- integração mantida com catálogo remoto via Netlify Functions
- fallback local preservado
- jogos jogáveis dentro do app:
  - memória
  - alfabetização
  - matemática
  - formas
  - cores
  - labirinto
  - puzzle

## Validação
- npm run typecheck ✅
- npm run build ✅

## Deploy
1. Extrair por cima da pasta do projeto local
2. Rodar:
   - npm install
   - npm run build
   - git add .
   - git commit -m "Premium kids UI V8"
   - git push
3. Aguardar deploy no Netlify
